  -react 파트-
  1) React에서 input 태그 추가(type="file")
  2) input 태그에서 선택한 파일을 state 변수에 저장
  3) 도서정보(문자,숫자) + 파일정보 모두를 저장할 수 있는 FormData()

  -spring 파트-
  1) Controller에서 MultipartFile 객체를 이용해 전달되는 파일 데이터를 받음
  2) application.properties 파일에 업로드할 파일 위치 지정
  3) 전달받은 파일을 업로드하기 위해 파일명을 생성
  4) 파일 업로드 코드 작성
